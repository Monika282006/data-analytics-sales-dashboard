# Data Analytics – Sales Dashboard

## Project Overview

This project focuses on analyzing sales data and developing an interactive sales dashboard using Microsoft Power BI.

The project demonstrates the data analytics process, including data preparation, analysis, visualization, dashboard development, and presentation of business insights.

### Dashboard Preview

[![Sales Dashboard](Sales_Dashboard_Screenshot.png)](Sales_Dashboard_Screenshot.png)

## Objectives

- To analyze the given sales dataset.
- To clean and prepare the data for analysis.
- To calculate important sales and profitability metrics.
- To create meaningful data visualizations.
- To develop an interactive Power BI dashboard.
- To identify useful business insights from the sales data.

## Dataset

The sales dataset is used as the primary source for analysis and dashboard development.

Dataset file:

`sales_data.xlsx`

## Data Cleaning

The dataset was checked and prepared before visualization.

The data preparation process included:

- Checking missing values.
- Checking duplicate records.
- Verifying data types.
- Checking date fields.
- Reviewing numerical and categorical columns.
- Preparing the dataset for Power BI analysis.

## Tools Used

- Microsoft Excel
- Microsoft Power BI
- Microsoft PowerPoint

## Dashboard

The interactive sales dashboard was developed using Microsoft Power BI.

The dashboard includes:

- Total Sales
- Total Profit
- Quantity Sold
- Profit Margin
- Monthly Sales Trend
- Sales by Product Category
- Sales by Region
- Profit by Sales Representative
- Sales by Sales Channel
- Interactive slicers

## Key Performance Indicators

### Total Sales

Displays the overall sales generated from the dataset.

### Total Profit

Displays the total profit generated from sales.

### Quantity Sold

Shows the total quantity of products sold.

### Profit Margin

Shows the profitability of sales as a percentage.

## Visualizations

The dashboard contains the following visualizations:

1. Monthly Sales Trend
2. Sales by Product Category
3. Sales by Region
4. Profit by Sales Representative
5. Sales by Sales Channel

## Key Insights

The dashboard helps analyze:

- Overall sales performance.
- Profitability.
- Monthly sales trends.
- Product category performance.
- Regional sales performance.
- Sales representative performance.
- Sales channel performance.
